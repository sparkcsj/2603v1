    Chapter 02: 우리 반 간식 전쟁 - 첫 번째 데이터 분석 체험¶

    🎯 이 장의 학습 목표¶

    • 실제 데이터를 수집하고 그래프로 표현할 수 있어요
    • 파이썬 코드를 실행해서 막대그래프를 만들어봐요
    • 데이터를 보고 의미 있는 해석을 할 수 있어요

    예상 학습 시간: 약 5분

    📚 미리 알아야 할 것¶

    이전 장에서 구글 코랩을 열고 "Hello, Data Science!"를 출력해봤어요. 이번에는 그 코랩을 사용해서 실제 데이터를 시각화해봅니다!

    📖 핵심 개념: 데이터 시각화란?¶

    데이터 시각화는 마치 글로 쓴 숫자들을 그림으로 그려내는 마법과 같아요.

    "간식 선호도"라는 정보를 어떻게 표현할까요?

    ❌ 글로만 쓰면: "마라탕 8명, 떡볶이 6명, 치킨 10명, 디저트 5명"
✅ 그래프로 보면: 한눈에 "아! 치킨이 제일 인기네!" 알 수 있어요

    파이썬의 matplotlib 라이브러리는 이 작업을 쉽게 도와줘요.

    💡 잠깐! 라이브러리가 뭐예요?
    누군가 미리 만들어둔 코드 도구 상자 생각하면 돼요. 우리는 그 도구를 꺼내서 쓰기만 하면 된답니다!

    🔧 직접 해봐요¶

    Step 1: 간식 데이터 만들기¶

    구글 코랩을 열고 다음 코드를 입력한 후 실행 버튼(▶)을 클릭하세요.

    코드: 

    import matplotlib.pyplot as plt

# 우리 반 간식 선호도 데이터
간식 = ['마라탕', '떡볶이', '치킨', '디저트']
선호도 = [8, 6, 10, 5]  # 각 간식을 좋아하는 학생 수

# 막대그래프 그리기
plt.bar(간식, 선호도, color=['red', 'brown', 'gold', 'pink'])
plt.ylabel('선호하는 학생 수')
plt.title('우리 반이 가장 좋아하는 간식은?')
plt.show()

    실행 결과:
    막대그래프가 나타나고, 치킨 막대가 가장 길게 보일 거예요! 🎉

    ✅ 체크포인트: 그래프가 보이셨나요? 그렇다면 성공입니다!

    📝 전체 코드¶

    import matplotlib.pyplot as plt

간식 = ['마라탕', '떡볶이', '치킨', '디저트']
선호도 = [8, 6, 10, 5]

plt.bar(간식, 선호도, color=['red', 'brown', 'gold', 'pink'])
plt.ylabel('선호하는 학생 수')
plt.title('우리 반이 가장 좋아하는 간식은?')
plt.show()

    ⚠️ 주의할 점¶

    1. 리스트의 개수를 맞춰야 해요
    간식과 선호도 리스트는 순서대로 짝을 이루어야 해요. ['마라탕', '떡볶이']와 [8, 6]처럼요.

    2. 한글이 깨질 수도 있어요
    혹시 글자가 깨진다면, 코드 맨 앞에 다음을 추가하세요: 

    plt.rcParams['font.family'] = 'DejaVu Sans'

    ✅ 점검하기¶

    1. 우리가 그린 그래프에서 가장 인기 있는 간식은 뭔가요?

      정답 확인 치킨입니다! 선호도 값이 10으로 가장 크니까요.

    2. 코드의 color=['red', 'brown', 'gold', 'pink']는 뭐하는 부분일까요?

      정답 확인 각 막대의 색깔을 지정하는 부분입니다. 마라탕은 빨강, 떡볶이는 갈색... 이런 식으로요!

    📌 이 장의 핵심 정리¶

    • ✅ 데이터 시각화: 숫자를 그래프로 그려내면 한눈에 의미를 파악할 수 있어요
    • ✅ 파이썬의 힘: matplotlib을 사용하면 복잡한 데이터도 쉽게 아름다운 그래프로 만들 수 있어요
    • ✅ 당신도 할 수 있어요: 코드를 이해하지 못해도 실행 버튼만 눌러도 멋진 결과가 나온다는 거!
