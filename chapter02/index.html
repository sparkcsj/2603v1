    Chapter 02: 우리 반 간식 전쟁 - 첫 번째 데이터 분석 체험¶

    🎯 이 장의 학습 목표¶

    • 실제 데이터를 수집하고 그래프로 그릴 수 있습니다
    • 파이썬이 데이터를 정리하는 도구임을 이해합니다
    • 데이터 분석 결과로부터 의미 있는 해석을 찾을 수 있습니다

    예상 학습 시간: 약 5분

    📚 미리 알아야 할 것¶

    이전 장에서 배운 파이썬의 기본 실행 환경(구글 코랩)이 준비되어 있으면 좋습니다. 코드를 직접 작성하지는 않으니 걱정하지 않으셔도 괜찮아요!

    📖 핵심 개념: 데이터 시각화란?¶

    데이터 시각화는 숫자들을 그래프나 그림으로 바꾸는 것입니다. 마치 "우리 반이 좋아하는 간식" 설문조사 결과를 마구잡이 숫자 나열 대신 한눈에 보이는 막대그래프로 표현하는 것처럼요.

    왜 필요할까요? - 숫자만 봐서는 잘 안 보여요: "마라탕 15명, 떡볶이 18명, 치킨 22명, 디저트 12명" - 그래프로 보면 한눈에 보여요: 🍗 치킨이 가장 높은 막대로 나타나요!

    🔨 따라하기¶

    Step 1: 데이터 준비하고 그래프 그리기¶

    구글 코랩을 열고 다음 코드를 복사해서 붙여넣기 하세요. (직접 타이핑할 필요 없어요!)

    코드: 

    import matplotlib.pyplot as plt

# 우리 반의 간식 선호도 데이터
간식 = ['마라탕', '떡볶이', '치킨', '디저트']
투표수 = [15, 18, 22, 12]

# 막대그래프 그리기
plt.bar(간식, 투표수, color=['red', 'orange', 'brown', 'pink'])
plt.xlabel('간식 종류')
plt.ylabel('투표수')
plt.title('우리 반이 가장 좋아하는 간식은?')
plt.show()

    실행 결과: 

    ▂▃▃▅
막대그래프가 나타나면 성공! 
(치킨 막대가 가장 길게 보여요)

    ✅ 체크포인트: 화면에 색깔 있는 막대 4개가 나타났나요? 그렇다면 완벽해요!

    📝 전체 코드¶

    import matplotlib.pyplot as plt

간식 = ['마라탕', '떡볶이', '치킨', '디저트']
투표수 = [15, 18, 22, 12]

plt.bar(간식, 투표수, color=['red', 'orange', 'brown', 'pink'])
plt.xlabel('간식 종류')
plt.ylabel('투표수')
plt.title('우리 반이 가장 좋아하는 간식은?')
plt.show()

    ⚠️ 주의할 점¶

    1. 데이터 입력 실수: 간식 이름과 투표수의 개수가 같아야 합니다. (둘 다 4개)
    2. 코드 복사 실수: 따옴표(' ')가 일반 따옴표가 아닌지 확인하세요. 구글 코랩에서 바로 복사하면 안 돼요!

    ✅ 점검하기¶

    1. 이 그래프가 보여주는 것은? 우리 반이 어떤 간식을 가장 좋아하는지

    2. 막대의 길이가 다른 이유는? 각 간식을 선택한 사람 수가 달라서요

    3. 색깔이 다른 이유는? 각 간식을 구분하기 쉽게 하려고요

    💡 더 자세한 설명 보기 **데이터 시각화의 위력**: - 숫자로 보면: 비교하기 어려워요 - 그래프로 보면: 한눈에 "치킨 > 떡볶이 > 마라탕 > 디저트" 순서가 보여요! 이것이 바로 **데이터과학의 첫 번째 힘**입니다.

    🤔 스스로 점검해 봐요¶

    • 코드를 복사해서 실행할 수 있나요?
    • 그래프에 4개의 막대가 보이나요?
    • 막대의 높이 차이가 투표수 차이를 나타낸다는 것을 이해했나요?
