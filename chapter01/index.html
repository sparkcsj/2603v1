    왜 데이터일까? - 외고인의 일상 속 숨은 데이터 찾기¶

    🎯 이 장에서 배우는 것¶

    • 내 주변의 다양한 데이터를 발견할 수 있다
    • 데이터가 무엇인지 쉬운 말로 설명할 수 있다
    • 데이터과학이 나의 일상과 연결된다는 것을 느낄 수 있다

    예상 학습 시간: 약 7분

    📚 핵심 개념¶

    개념: 데이터란 무엇일까?¶

    비유로 시작해볼까요?
    데이터는 마치 일기장에 적는 하루의 기록과 같아요. "오늘 급식 맛있었다", "3교시에 졸았다", "친구한테 카톡 10분 만에 답장했다" 같은 모든 기록이 데이터랍니다!

    정확한 정의
    데이터는 우리가 관찰하고 기록할 수 있는 모든 정보를 말해요. 숫자일 수도 있고, 글자일 수도 있고, 심지어 이모티콘도 데이터가 될 수 있어요.

    예시로 확인
    - 오늘 급식 메뉴: "김치찌개" → 데이터 ✅ - 내 수면시간: "5.5시간" → 데이터 ✅ - 좋아하는 과목: "영어" → 데이터 ✅ - 카톡 읽씹 시간: "3분 27초" → 데이터 ✅

    🔨 따라하기¶

    Step 1: 내 주변 데이터 3개 찾기¶

    미션: 지금 이 순간 여러분 주변에서 데이터 3개를 찾아보세요!

    힌트: 

    1. 지금 시각은? (예: 오후 7시 32분)
2. 오늘 마신 물 양은? (예: 500ml)
3. 지금 기분은? (예: 약간 피곤함)

    💡 잠깐! 찾으셨나요? 어때요, 생각보다 쉽죠?
    주변을 둘러보면 모든 게 데이터랍니다!

    🎮 퀴즈: 이것도 데이터일까?¶

    다음 중 데이터가 아닌 것을 골라보세요:

    1. 오늘 아침 기상 시각
    2. 내가 좋아하는 K-POP 가수
    3. 어제 본 넷플릭스 영화 제목
    4. (없음, 전부 데이터!)
    정답 확인 **정답: 4번** 모두 데이터예요! 시각(숫자), 이름(문자), 제목(문자) 모두 기록하고 분석할 수 있는 정보랍니다. 😊

    📊 데이터과학이란?¶

    graph LR A[일상 속 데이터] --> B[수집하고 정리] B --> C[분석하고 해석] C --> D[의미있는 발견!] style D fill:#FFE66D

    데이터과학은 이렇게 모은 데이터를 분석해서 숨겨진 패턴이나 의미를 찾아내는 학문이에요.

    예를 들면: - 급식 만족도 데이터 → 학생들이 정말 좋아하는 메뉴 발견 - 수면시간 데이터 → 성적과의 관계 분석 - 외국어 학습시간 데이터 → 효과적인 공부법 찾기

    ⚠️ 주의할 점¶

    데이터와 정보는 다르답니다
    데이터는 가공되지 않은 날것의 기록이고, 정보는 데이터를 분석해서 얻은 의미있는 결과예요. 이 차이는 다음 장에서 더 자세히 배워볼 거예요!

    ✅ 점검하기¶

    1. 데이터를 한 문장으로 설명한다면?
    정답 확인 관찰하고 기록할 수 있는 모든 정보를 데이터라고 해요.
    1. 여러분이 오늘 만들어낸 데이터 1개를 떠올려보세요. 무엇인가요?
    예시 답안 - 오늘 등교 시각 - 1교시 출석 여부 - 점심시간에 먹은 음식의 종류 → 정답은 무궁무진해요! 😄
