    Chapter 08. 3대 메시지 - 우리가 함께 기억할 것들¶

    🎯 이 장의 학습 목표¶

    • 이 장을 마치면 데이터과학 학습의 핵심 마인드를 이해할 수 있습니다
    • 이 장을 마치면 앞으로의 학습 여정에 자신감을 가질 수 있습니다
    • 예상 학습 시간: 약 4분

    📚 미리 알아야 할 것¶

    • 지금까지 7차시 동안 우리는 첫 코드를 실행하고, 데이터를 다뤄봤어요
    • 이제 본격적인 학습을 시작하기 전, 꼭 기억해야 할 것들을 짚어볼게요

    💬 시작하며¶

    여러분, 첫 수업 어떠셨나요? 혹시 "나는 못할 것 같아" 또는 "어려워 보이는데..."라는 생각이 드셨나요?

    괜찮아요! 모두가 처음엔 그래요. 지금부터 앞으로의 여정을 함께할 세 가지 약속을 나눌게요. 이것만 기억하면 충분합니다.

    📚 핵심 개념¶

    메시지 1: 두려움 없이 🌱¶

    "파이썬은 외우는 게 아니에요"

    파이썬은 마치 자전거와 같아요. 자전거 구조를 완벽히 외운다고 타는 게 아니죠. 넘어지고, 다시 타보고, 균형을 잡으면서 배우는 거예요.

    • 코드를 암기할 필요 없어요
    • 에러가 나도 괜찮아요 (에러는 학습의 신호!)
    • 모두 함께 배우는 과정이에요

    💡 기억하세요: 프로그래머들도 매일 검색하며 코드를 씁니다. 외우는 사람은 없어요!

    메시지 2: 흥미롭게 ✨¶

    "여러분의 일상이 데이터가 됩니다"

    오늘 여러분이 다룬 데이터, 기억나시나요?

    • 좋아하는 음악 차트
    • 내가 사는 동네의 날씨
    • 관심 있는 주제의 통계

    앞으로 매 시간, 여러분의 관심사가 수업의 재료가 될 거예요. 게임을 좋아한다면? 게임 데이터를 분석해봐요. 음식에 관심 있다면? 맛집 리뷰를 데이터로 만들어봐요.

    graph LR A[내 관심사] --> B[실제 데이터] B --> C[파이썬 코드] C --> D[의미있는 결과] D --> A style A fill:#FFE6E6 style D fill:#E6F3FF

    ✨ 포인트: 데이터과학은 나의 궁금증을 해결하는 도구예요!

    메시지 3: 내 손으로 직접 🖐️¶

    "실행해보는 것이 전부입니다"

    이것은 마치 요리와 같아요. 레시피를 100번 읽는 것보다, 한 번 직접 만들어보는 게 낫죠.

    앞으로의 학습 패턴: 1. 따라하기: 코드를 그대로 실행해봐요 2. 고쳐보기: 숫자나 단어를 바꿔봐요 3. 응용하기: 내 데이터로 시도해봐요

    🔨 약속 확인하기¶

    자, 이제 우리의 약속을 한번 더 정리해볼게요!

    mindmap root((1년간의 약속)) 두려움 없이 외우지 않기 에러 환영하기 함께 배우기 흥미롭게 내 관심사로 실제 데이터로 의미있는 결과로 내 손으로 직접 따라하기 고쳐보기 응용하기

    💪 여러분에게¶

    첫째, 코드가 안 외워진다고 걱정하지 마세요. 필요한 건 구글과 이 교재가 알려줄 거예요.

    둘째, 재미있어야 계속할 수 있어요. 지루하면? 여러분이 좋아하는 주제로 바꿔보세요!

    셋째, 눈으로만 보지 말고 꼭 실행해보세요. 10번 읽는 것보다 1번 실행이 낫습니다.

    🌟 선생님의 약속: 1년 뒤, 여러분은 스스로 데이터를 찾고, 분석하고, 인사이트를 발견하는 사람이 되어 있을 거예요. 제가 함께할게요!

    ⚠️ 주의할 점¶

    완벽을 추구하지 마세요 - 첫 코드부터 완벽할 순 없어요 - 에러 메시지는 적(敵)이 아니라 선생님이에요

    비교하지 마세요 - 다른 사람보다 느려도 괜찮아요 - 여러분만의 속도로 가세요

    ✅ 스스로 점검해 봐요¶

    1. 파이썬 코드를 외워야 한다? ⭕ / ❌
    정답 확인 ❌ 외울 필요 없어요! 필요할 때 찾아 쓰면 됩니다.
    1. 에러가 나면 잘못하고 있는 것이다? ⭕ / ❌
    정답 확인 ❌ 에러는 배움의 과정이에요. 오히려 환영해야 합니다!
    1. 가장 중요한 것은 무엇인가요?
    정답 확인 직접 실행해보는 것! 눈으로만 보지 말고 손으로 쳐보세요.

    📌 이 장의 핵심 정리¶

    ✅ 두려움 없이: 파이썬은 외우는 것이 아니라 활용하는 도구
    ✅ 흥미롭게: 내 관심사와 실제 데이터로 배우기
    ✅ 내 손으로 직접: 따라하고, 고쳐보고, 응용하기
