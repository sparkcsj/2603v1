    Chapter 05. 우리 반의 '하루'를 한 장의 그림으로 - Word Cloud 만들기¶

    🎯 이 장에서 배우는 것¶

    • 텍스트 데이터를 워드 클라우드로 시각화할 수 있다
    • 자주 등장하는 단어일수록 크게 표현되는 원리를 이해한다
    • 단어의 빈도를 활용한 감정 분석의 기초를 경험한다

    📚 핵심 개념¶

    개념: 워드 클라우드(Word Cloud)¶

    비유로 이해하기: 워드 클라우드는 마치 학급 설문 결과를 벽에 붙일 때, 많은 친구들이 쓴 단어는 크게, 적은 친구들이 쓴 단어는 작게 붙이는 것과 같아요.

    정확한 정의: 텍스트 데이터에서 단어의 출현 빈도를 시각적 크기로 표현하는 시각화 기법입니다.

    예시: "피곤" 10명, "행복" 3명 → "피곤"이 훨씬 크게 표시됨

    graph LR A[텍스트 수집] --> B[빈도 계산] B --> C[크기 결정] C --> D[워드 클라우드 생성]

    🔨 따라하기¶

    Step 1: 라이브러리 설치 및 데이터 준비¶

    코드: 

    from wordcloud import WordCloud
import matplotlib.pyplot as plt

# 우리 반 학생들이 적은 '오늘의 단어'
words = "피곤 피곤 피곤 행복 행복 설렘 짜증 피곤 행복 설렘 피곤"

    Step 2: 워드 클라우드 만들기¶

    코드: 

    # 워드 클라우드 생성
wc = WordCloud(font_path='malgun', width=800, height=400, 
               background_color='white').generate(words)

# 화면에 표시
plt.figure(figsize=(10, 5))
plt.imshow(wc)
plt.axis('off')
plt.show()

    실행 결과: "피곤"이 가장 크게, "행복", "설렘"이 중간 크기로, "짜증"이 작게 표시됩니다.

    💡 잠깐! font_path='malgun'은 한글 표시를 위한 설정이에요. 컴퓨터에 맑은 고딕 폰트가 없다면 'gulim'으로 바꿔보세요!

    📝 전체 코드¶

    from wordcloud import WordCloud
import matplotlib.pyplot as plt

# 데이터 준비
words = "피곤 피곤 피곤 행복 행복 설렘 짜증 피곤 행복 설렘 피곤"

# 워드 클라우드 생성 및 출력
wc = WordCloud(font_path='malgun', width=800, height=400,
               background_color='white').generate(words)

plt.figure(figsize=(10, 5))
plt.imshow(wc)
plt.axis('off')
plt.title('우리 반의 오늘')
plt.show()

    ⚠️ 주의할 점¶

    한글 폰트 오류: 한글이 □□□로 표시된다면 font_path 설정을 확인하세요. Windows는 'malgun', Mac은 'AppleGothic'을 사용해요.

    단어 띄어쓰기: 단어는 반드시 공백으로 구분해야 해요. "피곤피곤피곤"은 한 단어로 인식됩니다!

    ✅ 점검하기¶

    1. 워드 클라우드에서 단어의 크기는 무엇을 나타내나요?
    정답 확인단어의 출현 빈도(많이 나올수록 크게 표시됨)를 나타냅니다.
    1. background_color='white'를 'black'으로 바꾸면 어떻게 될까요?
    정답 확인배경이 검은색으로 바뀌고, 단어는 다른 색으로 표시됩니다.
