    📖 핵심 개념: 감정 분석이란?¶

    감정 분석은 마치 친구가 쓴 일기를 읽고 기분을 짐작하는 것처럼, AI가 텍스트 속 감정을 자동으로 찾아내는 기술이에요.

    정확히 말하면: - 문장이나 글을 읽고 - 그 안의 감정을 긍정😊 / 부정😢 / 중립😐 중 하나로 분류하는 것

    실제 예시: - "오늘 수학 시험 봤는데 어려웠어" → 부정 😢 - "친구들과 놀았던 시간이 정말 재미있었어!" → 긍정 😊 - "오늘 날씨는 맑습니다" → 중립 😐

    💡 신기한 점: AI는 단어 하나하나를 분석해서 문장 전체의 감정을 추측한답니다!

    🔨 따라하기: 우리 반 감정 분석하기¶

    Step 1: 필요한 도구 준비하기¶

    구글 코랩을 열고, 아래 코드를 복사해서 붙여넣고 실행하세요.

    # 감정 분석 도구 설치
!pip install transformers torch

from transformers import pipeline

# 감정 분석기 불러오기
sentiment = pipeline("sentiment-analysis", 
                     model="nlptown/bert-base-multilingual-uncased-sentiment")

# 우리 반 학생들의 일상 문장들
sentences = [
    "오늘 과학 실험이 정말 재미있었어!",
    "숙제가 너무 많아서 힘들었어",
    "점심시간에 친구를 만났어",
    "운동회에서 우리 반이 1등을 했어!",
    "시험을 망쳤어"
]

# 각 문장의 감정 분석
for sentence in sentences:
    result = sentiment(sentence)[0]
    print(f"'{sentence}'")
    print(f"→ 감정: {result['label']}, 신뢰도: {result['score']:.1%}\n")

    실행 결과: 

    '오늘 과학 실험이 정말 재미있었어!'
→ 감정: POSITIVE, 신뢰도: 95.2%

'숙제가 너무 많아서 힘들었어'
→ 감정: NEGATIVE, 신뢰도: 87.3%

    Step 2: 결과를 그래프로 보기¶

    import matplotlib.pyplot as plt

# 감정 카운팅
positive = 0
negative = 0
neutral = 0

for sentence in sentences:
    result = sentiment(sentence)[0]['label']
    if result == 'POSITIVE':
        positive += 1
    elif result == 'NEGATIVE':
        negative += 1
    else:
        neutral += 1

# 파이 차트 그리기
emotions = ['긍정 😊', '부정 😢', '중립 😐']
counts = [positive, negative, neutral]
colors = ['#FFD700', '#FF6B6B', '#95A5A6']

plt.pie(counts, labels=emotions, colors=colors, autopct='%1.1f%%')
plt.title('우리 반의 감정 분포')
plt.show()

    📝 전체 코드¶

    # 1단계: 설치 및 준비
!pip install transformers torch
from transformers import pipeline
import matplotlib.pyplot as plt

sentiment = pipeline("sentiment-analysis", 
                     model="nlptown/bert-base-multilingual-uncased-sentiment")

# 2단계: 감정 분석
sentences = [
    "오늘 과학 실험이 정말 재미있었어!",
    "숙제가 너무 많아서 힘들었어",
    "점심시간에 친구를 만났어",
    "운동회에서 우리 반이 1등을 했어!",
    "시험을 망쳤어"
]

positive = negative = neutral = 0

for sentence in sentences:
    result = sentiment(sentence)[0]['label']
    score = sentiment(sentence)[0]['score']
    print(f"'{sentence}' → {result} ({score:.1%})")

    if result == 'POSITIVE': positive += 1
    elif result == 'NEGATIVE': negative += 1
    else: neutral += 1

# 3단계: 시각화
emotions = ['긍정 😊', '부정 😢', '중립 😐']
counts = [positive, negative, neutral]
colors = ['#FFD700', '#FF6B6B', '#95A5A6']

plt.pie(counts, labels=emotions, colors=colors, autopct='%1.1f%%')
plt.title('우리 반의 감정 분포')
plt.show()

    ✅ 점검하기¶

    1. 감정 분석은 어떤 작업일까요?

      정답 확인텍스트 속 감정을 긍정/부정/중립으로 자동 분류하는 일이에요.

    2. 우리 코드에서 "신뢰도 95%"가 의미하는 것은?

      정답 확인AI가 이 문장을 95% 확률로 긍정이라고 생각한다는 뜻이에요.

    3. 파이 차트가 보여주는 정보는?

      정답 확인우리 반 전체 문장 중 긍정/부정/중립이 각각 몇 %를 차지하는지를 보여줘요.

    🌟 이 장의 핵심 정리¶

    • ✅ 감정 분석: AI가 텍스트의 감정을 자동으로 읽는 기술
    • ✅ 분류 방식: 긍정 / 부정 / 중립 세 가지로 나눔
    • ✅ 신뢰도: 각 분석 결과에는 확신 정도(%)가 함께 제시됨
    • ✅ 우리 반 데이터: 수집한 감정 데이터를 시각화해서 패턴을 발견할 수 있음
