    Chapter 06: 우리 반의 감정 분석 - 긍정, 부정, 중립 읽어내기¶

    🎯 이 장의 학습 목표¶

    • 감정 분석(Sentiment Analysis)이 무엇인지 이해할 수 있어요
    • 텍스트를 긍정/부정/중립으로 분류하는 코드를 직접 실행할 수 있어요
    • AI가 어떻게 우리의 감정을 읽어내는지 체험할 수 있어요

    예상 학습 시간: 약 7분

    📚 미리 알아야 할 것¶

    지난 장에서 데이터를 수집하고 정리하는 방법을 배웠어요. 이번에는 그 데이터 안에 숨어 있는 감정을 찾아내는 과정을 배우게 됩니다.

    📚 핵심 개념¶

    감정 분석(Sentiment Analysis)이란?¶

    감정 분석은 마치 당신의 친한 친구가 당신의 말투와 단어를 듣고 "지금 기분 좋아 보여" 또는 "뭔가 힘들어 보여"라고 말하는 것처럼, AI가 텍스트에서 긍정, 부정, 중립의 감정을 자동으로 읽어내는 기술입니다.

    예를 들어: - 긍정 😊: "오늘 수학 시험 잘 봤어! 너무 행복해" - 부정 😢: "수학이 너무 어려워. 한 문제도 못 풀었어" - 중립 😐: "오늘 수학 시험을 봤다"

    AI는 학습된 패턴을 통해 단어들의 의미를 파악하고, 감정 점수를 계산해서 분류합니다.

    💡 잠깐! "AI가 감정을 안다고?" 신기하죠? 사실 AI는 감정을 느끼지 못하지만, 패턴을 인식하는 능력이 있어서 우리의 감정을 분류할 수 있답니다!

    🔨 따라하기¶

    Step 1: 감정 분석 라이브러리 설치 및 준비¶

    구글 코랩을 열고 다음 코드를 실행하세요:

    # TextBlob 라이브러리 설치
!pip install textblob

from textblob import TextBlob

# 우리 반 학생들의 의견 데이터
comments = [
    "오늘 수학 시험 너무 재미있었어!",
    "이 숙제는 정말 어렵고 싫어",
    "오늘 날씨는 흐렸다",
    "친구들이랑 웃고 놀아서 좋았어",
    "뭔가 피곤해"
]

# 각 댓글의 감정 분석
for comment in comments:
    blob = TextBlob(comment)
    polarity = blob.sentiment.polarity  # -1(부정)부터 +1(긍정)

    if polarity > 0.1:
        emotion = "😊 긍정"
    elif polarity < -0.1:
        emotion = "😢 부정"
    else:
        emotion = "😐 중립"

    print(f"'{comment}' → {emotion} (점수: {polarity:.2f})")

    실행 결과: 

    '오늘 수학 시험 너무 재미있었어!' → 😊 긍정 (점수: 0.60)
'이 숙제는 정말 어렵고 싫어' → 😢 부정 (점수: -0.67)
'오늘 날씨는 흐렸다' → 😐 중립 (점수: 0.00)
'친구들이랑 웃고 놀아서 좋았어' → 😊 긍정 (점수: 0.75)
'뭔가 피곤해' → 😢 부정 (점수: -0.50)

    Step 2: 감정 분포를 파이 차트로 시각화¶

    import matplotlib.pyplot as plt

# 감정 분류 결과 저장
emotions = []
for comment in comments:
    blob = TextBlob(comment)
    polarity = blob.sentiment.polarity

    if polarity > 0.1:
        emotions.append("긍정")
    elif polarity < -0.1:
        emotions.append("부정")
    else:
        emotions.append("중립")

# 각 감정 개수 세기
from collections import Counter
emotion_count = Counter(emotions)

# 파이 차트 그리기
plt.figure(figsize=(8, 6))
plt.pie(emotion_count.values(), labels=emotion_count.keys(), 
        autopct='%1.1f%%', colors=['#FFD700', '#FF6B6B', '#95E1D3'])
plt.title('우리 반의 감정 분석 결과')
plt.show()

    📝 전체 코드¶

    !pip install textblob
from textblob import TextBlob
import matplotlib.pyplot as plt
from collections import Counter

# 학생들의 의견 수집
comments = [
    "오늘 수학 시험 너무 재미있었어!",
    "이 숙제는 정말 어렵고 싫어",
    "오늘 날씨는 흐렸다",
    "친구들이랑 웃고 놀아서 좋았어",
    "뭔가 피곤해"
]

# 감정 분석
emotions = []
for comment in comments:
    blob = TextBlob(comment)
    polarity = blob.sentiment.polarity

    if polarity > 0.1:
        emotion = "긍정"
    elif polarity < -0.1:
        emotion = "부정"
    else:
        emotion = "중립"

    emotions.append(emotion)
    print(f"'{comment}' → {emotion}")

# 파이 차트 시각화
emotion_count = Counter(emotions)
plt.figure(figsize=(8, 6))
plt.pie(emotion_count.values(), labels=emotion_count.keys(), 
        autopct='%1.1f%%', colors=['#FFD700', '#FF6B6B', '#95E1D3'])
plt.title('우리 반의 감정 분석 결과')
plt.show()

    ⚠️ 주의할 점¶

    1. 한국어 분석의 한계: TextBlob은 영어에 최적화되어 있어서, 한국어 분석이 완벽하지 않을 수 있어요. 결과를 볼 때 "대략적인 경향"으로 해석하면 됩니다.

    2. 감정 점수 해석: -1부터 +1 사이의 값이 나오는데, 0에 가까울수록 중립이고, 1에 가까울수록 긍정, -1에 가까울수록 부정입니다.

    ✅ 점검하기¶

    1. 감정 분석이란 무엇인가요?

      정답 확인AI가 텍스트 데이터에서 긍정, 부정, 중립의 감정을 자동으로 읽어내는 기술입니다.

    2. TextBlob의 sentiment.polarity 값이 0.8이라면 어떤 감정인가요?

      정답 확인0.1보다 크므로 긍정(😊) 감정입니다. 0.8은 매우 강한 긍정을 의미합니다.

    3. 코드에서 emotion_count = Counter(emotions)는 무엇을 하나요?

      정답 확인emotions 리스트에서 각 감정이 몇 개씩 있는지 세어줍니다. {'긍정': 2, '부정': 2, '중립': 1} 처럼요.
