    Chapter 06. 우리 반의 감정 분석 - 긍정, 부정, 중립 읽어내기¶

    🎯 이 장에서 배우는 것¶

    • 감정 분석이 무엇인지 이해하고 설명할 수 있다
    • 텍스트를 긍정/부정/중립로 분류하는 코드를 실행할 수 있다
    • 우리 반 전체의 감정 분포를 시각화할 수 있다

    예상 학습 시간: 약 7분

    📚 핵심 개념¶

    개념: 감정 분석(Sentiment Analysis)¶

    비유로 이해하기: 감정 분석은 마치 우리가 친구의 표정을 보고 기분을 알아채는 것처럼, 컴퓨터가 문장을 읽고 그 감정을 파악하는 거예요.

    정확한 정의: 텍스트 데이터를 분석해서 긍정(😊), 부정(😢), 중립(😐) 같은 감정으로 자동 분류하는 기술입니다.

    예시로 확인: - "오늘 정말 즐거웠어!" → 😊 긍정 - "시험이 너무 어려웠어..." → 😢 부정
    - "오늘은 학교에 갔다." → 😐 중립

    graph LR A["텍스트 입력<br/>'오늘 정말 즐거웠어!'"] --> B[감정 분석 AI] B --> C["결과: 긍정 😊"] style A fill:#e1f5ff style B fill:#fff4e1 style C fill:#d4f4dd

    🔨 따라하기¶

    Step 1: 감정 분석 라이브러리 설치하기¶

    코드: 

    # 감정 분석 도구 설치
!pip install textblob

from textblob import TextBlob

    Step 2: 문장의 감정 분석하기¶

    코드: 

    # 분석할 텍스트 (예: 긍정적인 가사 또는 부정적인 뉴스)
text = "I love this beautiful world and I feel so happy today!"

blob = TextBlob(text)
sentiment = blob.sentiment.polarity # -1(부정) ~ 1(긍정)

if sentiment > 0:
    print(f"😊 분석 결과: 이 글은 아주 '긍정적({sentiment:.2f})'인 상태네요!")
elif sentiment < 0:
    print(f"😭 분석 결과: 이 글은 다소 '부정적({sentiment:.2f})'인 기운이 느껴져요.")
else:
    print("😐 분석 결과: 아주 중립적인 글입니다.")

    실행 결과: 

    😊 분석 결과: 이 글은 아주 '긍정적(0.78)'인 상태네요!

    💡 잠깐! polarity 점수는 -1에서 1 사이 숫자예요. 양수면 긍정, 음수면 부정이랍니다!

    📝 전체 코드¶

    # 1. 라이브러리 설치 및 불러오기
!pip install textblob
from textblob import TextBlob
import matplotlib.pyplot as plt

#텍스트 감정 분석기
from textblob import TextBlob

# 분석할 텍스트 (예: 긍정적인 가사 또는 부정적인 뉴스)
text = "I love this beautiful world and I feel so happy today!"

blob = TextBlob(text)
sentiment = blob.sentiment.polarity # -1(부정) ~ 1(긍정)

if sentiment > 0:
    print(f"😊 분석 결과: 이 글은 아주 '긍정적({sentiment:.2f})'인 상태네요!")
elif sentiment < 0:
    print(f"😭 분석 결과: 이 글은 다소 '부정적({sentiment:.2f})'인 기운이 느껴져요.")
else:
    print("😐 분석 결과: 아주 중립적인 글입니다.")

    ⚠️ 주의할 점¶

    1. 영어가 더 정확해요: TextBlob은 영어 분석이 가장 정확합니다. 한국어는 KoNLPy 같은 한국어 전용 라이브러리를 사용하면 더 좋아요!

    2. 감정은 복잡해요: "시험은 어려웠지만 재밌었어" 같은 문장은 AI도 헷갈릴 수 있답니다.

    ✅ 점검하기¶

    1. 감정 분석은 무엇을 하는 기술인가요?
    정답 확인 텍스트를 읽고 긍정, 부정, 중립 같은 감정으로 자동 분류하는 기술입니다.
    1. polarity 점수가 0.5라면 어떤 감정일까요?
    정답 확인 양수이므로 긍정 감정입니다. (0.1보다 크므로 😊 긍정)
    1. 우리 반 20명의 감정을 분석했더니 긍정 12명, 부정 3명, 중립 5명이었어요. 어떤 의미일까요?
    정답 확인 우리 반의 60%가 긍정적인 감정 상태로, 전반적으로 분위기가 좋다고 해석할 수 있어요!
