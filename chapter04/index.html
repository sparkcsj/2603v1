    📚 미리 알아야 할 것¶

    이전 장에서 우리는 구글 폼으로 설문을 만들고 실시간 데이터를 모았어요. 이번에는 그 데이터를 분석하기 위해 파일로 준비하는 과정을 배웁니다!

    📚 핵심 개념¶

    개념: CSV 파일이란?¶

    CSV는 마치 엑셀 표를 일반 텍스트로 저장한 것처럼 생각하면 돼요. 각 데이터가 쉼표로 구분되어 있어서 프로그래밍으로 쉽게 읽을 수 있답니다.

    구체적으로: - 이름, MBTI, 성별 같은 항목들이 쉼표로 구분됨 - 코랩(Colab)이나 파이썬이 바로 읽을 수 있는 형식 - 아주 가볍고 빠르게 처리됨

    실제 모습: 

    이름,MBTI,성별
김철수,ENFP,남
이영희,ISTJ,여

    🔨 따라하기¶

    Step 1: 구글 폼에서 CSV로 내보내기¶

    구글 폼 응답 탭에서:

    1. 응답 탭 클릭 → 스프레드시트 아이콘 클릭
    2. "새 스프레드시트 만들기" 선택
    3. 생성된 시트 우측 상단 ⋮ → CSV 형식으로 다운로드

    ✅ 체크포인트: 응답 (1).csv 같은 파일이 다운로드되었나요?

    Step 2: 코랩에 업로드하고 데이터 읽기¶

    import pandas as pd

# 로컬 파일 업로드 (왼쪽 파일 탭에서 드래그)
df = pd.read_csv('응답 (1).csv')

# 첫 5줄 확인
print(df.head())

    실행 결과: 

         이름   MBTI  성별
0   김철수   ENFP   남
1   이영희   ISTJ   여
2   박민수   INFP   남

    📝 전체 코드¶

    import pandas as pd
import matplotlib.pyplot as plt

# 1. 데이터 읽기
df = pd.read_csv('응답 (1).csv')

# 2. MBTI 빈도 계산
mbti_count = df['MBTI'].value_counts()

# 3. 막대 그래프로 시각화
plt.figure(figsize=(10, 6))
mbti_count.plot(kind='bar', color='skyblue')
plt.title('우리 반의 MBTI 분포', fontsize=14, fontweight='bold')
plt.xlabel('MBTI 유형')
plt.ylabel('명수')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

    ⚠️ 주의할 점¶

    1. 파일명 확인: 코드의 '응␣답␣(1).csv' 부분을 실제 파일명과 정확히 맞춰야 해요. (따옴표 안은 정확하게!)
    2. 한글 인코딩: 구글 폼이 한글로 되어 있으면, 파이썬이 자동으로 잘 읽어줍니다.

    ✅ 점검하기¶

    1. CSV 파일은 언제 사용하나요?

      정답 확인 데이터가 표 형식일 때, 프로그래밍으로 분석하기 위해 사용합니다. 엑셀보다 가볍고 빠르거든요!

    2. 코드에서 df['MBTI'].value_counts()는 무엇을 하나요?

      정답 확인 MBTI 열에서 각 유형이 몇 명씩 있는지 세어줍니다. (빈도 계산)
