    Chapter 04. 오늘 우리 반의 MBTI - 실시간 데이터 수집과 분석¶

    🎯 이 장에서 배우는 것¶

    • 구글 폼으로 수집한 데이터를 CSV 파일로 내보낼 수 있다
    • CSV 파일을 코랩에 업로드하고 불러올 수 있다
    • 범주형 데이터를 시각화할 수 있다

    예상 학습 시간: 약 6분

    📚 핵심 개념¶

    개념: CSV 파일과 데이터 수집¶

    비유로 이해하기: CSV 파일은 마치 반 친구들의 정보를 적은 출석부와 같아요. 각 줄이 한 명의 정보이고, 콤마(,)로 구분된 칸마다 이름, MBTI 같은 내용이 적혀있죠.

    정의: CSV(Comma-Separated Values)는 데이터를 콤마로 구분해서 저장하는 텍스트 파일 형식입니다.

    예시: 

    이름,MBTI
지훈,ENFP
서연,ISTJ
민준,INFJ

    🔨 따라하기¶

    Step 1: 구글 폼 데이터를 CSV로 내보내기¶

    1. 구글 폼 응답 화면에서 스프레드시트 만들기 클릭
    2. 스프레드시트에서 파일 → 다운로드 → CSV 선택
    3. 다운로드된 파일명을 mbti_data.csv로 변경

    Step 2: 코랩에 업로드하고 시각화하기¶

    코드: 

    import pandas as pd
import matplotlib.pyplot as plt

# 파일 업로드 (좌측 폴더 아이콘에서 드래그)
df = pd.read_csv('mbti_data.csv')

# MBTI 분포 세기
mbti_counts = df['MBTI'].value_counts()

# 파이 차트로 시각화
plt.pie(mbti_counts, labels=mbti_counts.index, autopct='%1.1f%%')
plt.title('우리 반 MBTI 분포')
plt.show()

    실행 결과: 

    우리 반의 MBTI 분포를 보여주는 파이 차트가 나타납니다!
ENFP: 25.0%, ISTJ: 20.0% 같은 식으로 비율이 표시돼요.

    📝 실습1 전체 코드¶

    import pandas as pd
import matplotlib.pyplot as plt

# CSV 파일 불러오기
df = pd.read_csv('mbti_data.csv')

# 데이터 확인
print(df.head())

# MBTI 빈도 계산
mbti_counts = df['MBTI'].value_counts()

# 시각화
plt.figure(figsize=(8, 6))
plt.pie(mbti_counts, labels=mbti_counts.index, autopct='%1.1f%%')
plt.title('우리 반 MBTI 분포', fontsize=15)
plt.show()

    📝 실습2 전체 코드¶

    import pandas as pd

# 샘플 데이터 생성
data = {
    '이름': ['민수', '지영', '준호', '서연', '동현', '예린', '태희', '승민'],
    'MBTI': ['ISTJ', 'ENFP', 'INTP', 'ESFJ', 'INFP', 'ENTJ', 'ISFP', 'ENFP'],
    '나이': [16, 15, 16, 15, 16, 15, 16, 15]
}

df = pd.DataFrame(data)

# 데이터 확인
print("📋 우리 반 데이터:")
print(df)
print("\n" + "="*40 + "\n")

# MBTI 분포 분석
print("📊 MBTI 유형별 분포:")
print(df['MBTI'].value_counts())
print("\n" + "="*40 + "\n")

# 요약 정보
print(f"✅ 전체 학생 수: {len(df)}명")
print(f"✅ MBTI 종류: {df['MBTI'].nunique()}가지")

    ⚠️ 주의할 점¶

    1. 파일명 확인: CSV 파일명이 코드의 read_csv() 안 이름과 정확히 일치해야 해요.
    2. 한글 깨짐: 한글이 깨지면 pd.read_csv('파일명.csv', encoding='cp949') 로 시도해보세요.

    ✅ 점검하기¶

    1. CSV 파일은 데이터를 어떻게 구분해서 저장하나요?
    정답 확인콤마(,)로 구분해서 저장합니다.
    1. value_counts()는 무엇을 계산하나요?
    정답 확인각 값이 몇 번 나타나는지 빈도를 계산합니다.
