    Chapter 04. 텍스트도 데이터다! Word Cloud와 감정분석 체험¶

    🎯 이 장에서 배우는 것¶

    • 텍스트 데이터를 멋진 Word Cloud로 시각화할 수 있다
    • TextBlob으로 텍스트의 감정을 자동 분석할 수 있다
    • 텍스트 마이닝이 인문학 분석에 어떻게 활용되는지 이해한다

    예상 학습 시간: 약 12분

    📚 핵심 개념¶

    개념 1: Word Cloud (워드 클라우드)¶

    Word Cloud는 텍스트 속 단어들을 빈도에 따라 다른 크기로 보여주는 시각화예요. 마치 인기 많은 노래가 음원 차트에서 큰 글씨로 표시되는 것처럼, 자주 등장하는 단어가 크게 나타나죠!

    개념 2: 감정분석 (Sentiment Analysis)¶

    감정분석은 텍스트에 담긴 감정을 자동으로 파악하는 기술이에요. "이 영화 정말 최고야!"는 긍정, "너무 지루해요"는 부정으로 판단하는 거죠. TextBlob은 -1(부정)에서 +1(긍정) 사이의 점수를 알려줘요.

    🔨 따라하기¶

    Step 1: Word Cloud 만들기¶

    from wordcloud import WordCloud
import matplotlib.pyplot as plt

# 마틴 루터 킹 연설문 일부
text = """
I have a dream that one day this nation will rise up.
I have a dream that my four little children will one day live in a nation.
Freedom! Let freedom ring from every mountainside!
"""

# Word Cloud 생성 (magma 컬러맵 적용)
wordcloud = WordCloud(width=800, height=400, 
                      background_color='white',
                      colormap='magma').generate(text)

# 시각화
plt.figure(figsize=(10, 5))
plt.imshow(wordcloud, interpolation='bilinear')
plt.axis('off')
plt.title('I Have a Dream - Word Cloud')
plt.show()

    실행 결과: "dream", "freedom", "nation" 같은 단어들이 크게 표시된 멋진 시각화가 나타나요! 🎨

    Step 2: 감정분석 해보기¶

    from textblob import TextBlob

# 감정분석 (설치: pip install textblob)
positive_text = "This speech is incredibly inspiring and hopeful!"
negative_text = "This is disappointing and sad."

blob1 = TextBlob(positive_text)
blob2 = TextBlob(negative_text)

print(f"긍정 문장 감정 점수: {blob1.sentiment.polarity:.2f}")  # 약 0.65
print(f"부정 문장 감정 점수: {blob2.sentiment.polarity:.2f}")  # 약 -0.50

    실행 결과: 

    긍정 문장 감정 점수: 0.65
부정 문장 감정 점수: -0.50

    💡 신기하죠? 컴퓨터가 텍스트의 감정을 숫자로 표현해줘요!

    📝 전체 코드¶

    from wordcloud import WordCloud
from textblob import TextBlob
import matplotlib.pyplot as plt

# 1. Word Cloud
text = """
I have a dream that one day this nation will rise up.
I have a dream that my four little children will one day live in a nation.
Freedom! Let freedom ring from every mountainside!
"""

wordcloud = WordCloud(width=800, height=400, 
                      background_color='white',
                      colormap='magma').generate(text)

plt.figure(figsize=(10, 5))
plt.imshow(wordcloud, interpolation='bilinear')
plt.axis('off')
plt.title('I Have a Dream - Word Cloud')
plt.show()

# 2. 감정분석
text_to_analyze = "I have a dream. This is incredibly inspiring!"
blob = TextBlob(text_to_analyze)
print(f"감정 점수: {blob.sentiment.polarity:.2f}")

    ⚠️ 주의할 점¶

    한글 Word Cloud: 한글 텍스트는 font_path로 한글 폰트를 지정해야 해요! 

    wordcloud = WordCloud(font_path='malgun.ttf', ...).generate(korean_text)

    감정분석의 한계: TextBlob은 영어에 최적화되어 있어요. 한글은 KoNLPy 같은 별도 라이브러리가 필요해요.

    ✅ 점검하기¶

    1. Word Cloud에서 단어 크기는 무엇을 의미하나요?
    정답 확인 해당 단어가 텍스트에 등장한 빈도(횟수)를 의미해요. 자주 나올수록 크게 표시됩니다!
    1. 감정분석 점수 0.7은 어떤 의미인가요?
    정답 확인 긍정적인 텍스트를 의미해요! 0에 가까우면 중립, +1에 가까울수록 긍정, -1에 가까울수록 부정이에요.
