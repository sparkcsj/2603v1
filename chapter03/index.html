    Chapter 03: 수면시간과 성적의 비밀 - 산점도로 패턴 읽기¶

    🎯 이 장의 학습 목표¶

    • 두 개의 변수 간 관계를 산점도로 나타낼 수 있습니다
    • 데이터에서 패턴을 발견하고 해석할 수 있습니다
    • 예상 학습 시간: 약 6분

    📚 미리 알아야 할 것¶

    지난 장에서 리스트와 기본 그래프를 배웠다면 충분해요. 어렵지 않습니다!

    📖 핵심 개념: 산점도와 관계 패턴¶

    산점도(Scatter Plot)란?¶

    산점도는 마치 밤하늘의 별들 배치를 보는 것처럼, 두 개 변수의 관계를 점으로 표현한 그래프예요.

    정의: 가로축(X축)과 세로축(Y축)에 각각 다른 데이터를 놓고, 각 데이터 쌍을 점으로 찍어 두 변수 간 관계를 시각화합니다.

    일상 예시: - "수면시간이 많을수록 성적이 높을까?" → 산점도로 확인 가능 - "커피를 많이 마실수록 잠을 덜 잘까?" → 패턴이 보여요

    🔨 따라하기¶

    Step 1: 가상 데이터 만들고 산점도 그리기¶

    목표: 학생 8명의 수면시간과 성적 데이터를 만들어 산점도로 표현하기

    코드: 

    import matplotlib.pyplot as plt

# 데이터: 8명 학생의 수면시간(시간)과 성적(점)
sleep_hours = [5, 6, 7, 8, 5.5, 7.5, 6, 8.5]
grades = [62, 70, 78, 85, 68, 82, 72, 88]

# 산점도 그리기
plt.figure(figsize=(8, 6))
plt.scatter(sleep_hours, grades, color='blue', s=100, alpha=0.6)
plt.xlabel('수면시간(시간)', fontsize=12)
plt.ylabel('성적(점)', fontsize=12)
plt.title('수면시간과 성적의 관계', fontsize=14, fontweight='bold')
plt.grid(True, alpha=0.3)
plt.show()

    실행 결과: 

    [산점도 이미지: 왼쪽 아래부터 오른쪽 위로 향하는 점들의 분포]
점들이 대각선 형태로 올라가는 패턴이 보여요!

    💡 패턴 읽기: 점들이 왼쪽 아래에서 오른쪽 위로 향하면 양의 관계입니다. 즉, 수면시간이 증가하면 성적도 증가한다는 뜻이에요!

    Step 2: 추세선 추가하여 관계 더 명확히 하기¶

    코드: 

    import numpy as np

# 추세선 그리기 (회귀선)
z = np.polyfit(sleep_hours, grades, 1)  # 직선 방정식 계산
p = np.poly1d(z)
x_line = np.linspace(5, 8.5, 100)

plt.figure(figsize=(8, 6))
plt.scatter(sleep_hours, grades, color='blue', s=100, alpha=0.6, label='실제 데이터')
plt.plot(x_line, p(x_line), color='red', linewidth=2, label='추세선')
plt.xlabel('수면시간(시간)', fontsize=12)
plt.ylabel('성적(점)', fontsize=12)
plt.title('수면시간과 성적 - 추세선 포함', fontsize=14, fontweight='bold')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

    실행 결과: 빨간 추세선이 데이터의 전체 흐름을 보여줍니다!

    📝 전체 코드¶

    import matplotlib.pyplot as plt
import numpy as np

# 데이터 정의
sleep_hours = [5, 6, 7, 8, 5.5, 7.5, 6, 8.5]
grades = [62, 70, 78, 85, 68, 82, 72, 88]

# 산점도 + 추세선
z = np.polyfit(sleep_hours, grades, 1)
p = np.poly1d(z)
x_line = np.linspace(5, 8.5, 100)

plt.figure(figsize=(8, 6))
plt.scatter(sleep_hours, grades, color='blue', s=100, alpha=0.6, label='실제 데이터')
plt.plot(x_line, p(x_line), color='red', linewidth=2, label='추세선')
plt.xlabel('수면시간(시간)', fontsize=12)
plt.ylabel('성적(점)', fontsize=12)
plt.title('수면시간과 성적의 관계', fontsize=14, fontweight='bold')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

    ⚠️ 주의할 점¶

    1. 변수 입력 순서 중요합니다 - scatter(X축 데이터, Y축 데이터) 순서를 반드시 지키세요 - 바뀌면 그래프가 완전히 달라요!

    2. 상관관계 ≠ 인과관계 - 점들이 패턴을 이루어도, "수면이 성적을 높인다"고 단정할 수 없어요 - "함께 변한다"는 관계만 보여줍니다

    ✅ 점검하기¶

    1. 산점도에서 점들이 대각선으로 올라가면 어떤 관계를 나타낼까요?
    정답 확인 양의 관계(양수 상관관계)입니다. 한쪽이 증가하면 다른 쪽도 증가하는 경향이 있다는 뜻이에요.
    1. 추세선을 그리는 이유는 무엇일까요?
    정답 확인 무수한 점들 사이의 전체적인 흐름을 한눈에 파악하기 위해서입니다. 마치 "큰 그림"을 보는 거죠!
