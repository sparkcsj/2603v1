    수면시간과 성적의 비밀 - 산점도로 패턴 읽기¶

    🎯 이 장에서 배우는 것¶

    • 두 변수 사이의 관계를 산점도로 표현할 수 있다
    • 데이터에서 패턴을 발견하고 해석할 수 있다
    • 상관관계의 개념을 이해한다

    예상 학습 시간: 약 6분

    📚 핵심 개념¶

    개념: 산점도(Scatter Plot)¶

    비유로 시작: 산점도는 마치 별자리를 보는 것과 같아요. 밤하늘의 별들처럼 데이터를 점으로 찍어서, 그 패턴을 발견하는 거예요!

    정확한 정의: 두 변수의 값을 x축과 y축에 표시하여 점으로 나타낸 그래프입니다. 점들의 분포를 보면 두 변수 사이의 관계를 알 수 있어요.

    예시로 확인: "수면시간이 늘어나면 성적도 올라갈까?" 같은 질문에 답할 때 사용합니다.

    🔨 따라하기¶

    Step 1: 데이터 준비하고 산점도 그리기¶

    코드: 

    import matplotlib.pyplot as plt

# 대전외고 학생 8명의 데이터 (가상)
수면시간 = [7, 5, 8, 6, 4, 7.5, 5.5, 8.5]
성적 = [85, 70, 92, 78, 65, 88, 72, 95]

# 산점도 그리기
plt.scatter(수면시간, 성적)
plt.xlabel('수면시간(시간)')
plt.ylabel('성적(점)')
plt.title('수면시간과 성적의 관계')
plt.show()

    실행 결과: 

    오른쪽 위로 올라가는 점들의 패턴이 보여요!
→ 수면시간이 많을수록 성적이 높아지는 경향

    💡 발견! 점들이 대각선 방향으로 모여 있나요? 이것이 바로 양의 상관관계예요!

    📝 전체 코드¶

    import matplotlib.pyplot as plt

# 데이터 생성
수면시간 = [7, 5, 8, 6, 4, 7.5, 5.5, 8.5]
성적 = [85, 70, 92, 78, 65, 88, 72, 95]

# 산점도 시각화
plt.scatter(수면시간, 성적, color='blue', s=100)
plt.xlabel('수면시간(시간)')
plt.ylabel('성적(점)')
plt.title('수면시간과 성적의 관계')
plt.grid(True, alpha=0.3)
plt.show()

    ⚠️ 주의할 점¶

    1. 상관관계 ≠ 인과관계: 수면시간이 많다고 무조건 성적이 오르는 건 아니에요. 다른 요인(공부시간, 집중도 등)도 영향을 줍니다.

    2. 극단값 주의: 한 명이 3시간 자고 100점을 받았다고 해서 패턴이 달라질 수 있어요.

    ✅ 점검하기¶

    1. 산점도에서 점들이 오른쪽 위로 올라가면 어떤 관계인가요?
    정답 확인 양의 상관관계입니다. 한 변수가 증가하면 다른 변수도 증가하는 경향이 있어요.
    1. plt.scatter(x, y)에서 x축, y축에는 각각 무엇이 들어가나요?
    정답 확인 x축: 독립변수(수면시간), y축: 종속변수(성적)가 들어갑니다.
