    Chapter 03. 우리 반 MBTI 데이터, 직접 분석해보기¶

    🎯 이 장에서 배우는 것¶

    • CSV 파일을 Google Colab에 업로드하고 불러올 수 있다
    • Pandas로 데이터를 확인하고 기본 정보를 출력할 수 있다
    • MBTI 유형별 분포를 확인하고 의미를 해석할 수 있다

    예상 학습 시간: 약 11분

    📚 핵심 개념¶

    개념: CSV 파일과 Pandas¶

    비유로 이해하기: CSV 파일은 엑셀의 단순한 버전이라고 생각하면 돼요. 행과 열로 정리된 데이터를 쉼표(,)로 구분해서 저장한 거예요. Pandas는 이런 표 형태의 데이터를 다루는 도구 상자 같은 거랍니다!

    정의: CSV(Comma-Separated Values)는 데이터를 쉼표로 구분한 텍스트 파일이고, Pandas는 Python에서 데이터를 표 형태로 다루는 라이브러리예요.

    🔨 따라하기¶

    Step 1: 데이터 파일 준비하고 불러오기¶

    먼저 우리 반 MBTI 데이터를 준비해볼게요. Google Colab 왼쪽의 📁 폴더 아이콘을 클릭한 후, CSV 파일을 드래그하면 업로드됩니다.

    코드: 

    import pandas as pd

# CSV 파일 불러오기
df = pd.read_csv('class_mbti.csv')

# 처음 5개 행 확인
print(df.head())

    실행 결과: 

       이름   MBTI  나이
0  민수   ISTJ   16
1  지영   ENFP   15
2  준호   INTP   16
3  서연   ESFJ   15
4  동현   INFP   16

    💡 잠깐! 파일이 없다면 직접 만들어도 돼요! 코드로 샘플 데이터를 만들어 봅시다.

    # 샘플 데이터 만들기
import pandas as pd

data = {
    '이름': ['민수', '지영', '준호', '서연', '동현', '예린', '태희', '승민'],
    'MBTI': ['ISTJ', 'ENFP', 'INTP', 'ESFJ', 'INFP', 'ENTJ', 'ISFP', 'ENFP'],
    '나이': [16, 15, 16, 15, 16, 15, 16, 15]
}

df = pd.DataFrame(data)
print(df)

    Step 2: MBTI 분포 확인하기¶

    이제 어떤 유형이 가장 많은지 세어볼까요?

    코드: 

    # MBTI 유형별 개수 세기
mbti_counts = df['MBTI'].value_counts()
print(mbti_counts)

# 전체 데이터 개수와 MBTI 종류 확인
print(f"\n전체 학생 수: {len(df)}명")
print(f"MBTI 종류: {df['MBTI'].nunique()}가지")

    실행 결과: 

    ENFP    2
ISTJ    1
INTP    1
ESFJ    1
INFP    1
ENTJ    1
ISFP    1

전체 학생 수: 8명
MBTI 종류: 7가지

    📝 전체 코드¶

    import pandas as pd

# 샘플 데이터 생성
data = {
    '이름': ['민수', '지영', '준호', '서연', '동현', '예린', '태희', '승민'],
    'MBTI': ['ISTJ', 'ENFP', 'INTP', 'ESFJ', 'INFP', 'ENTJ', 'ISFP', 'ENFP'],
    '나이': [16, 15, 16, 15, 16, 15, 16, 15]
}

df = pd.DataFrame(data)

# 데이터 확인
print("📋 우리 반 데이터:")
print(df)
print("\n" + "="*40 + "\n")

# MBTI 분포 분석
print("📊 MBTI 유형별 분포:")
print(df['MBTI'].value_counts())
print("\n" + "="*40 + "\n")

# 요약 정보
print(f"✅ 전체 학생 수: {len(df)}명")
print(f"✅ MBTI 종류: {df['MBTI'].nunique()}가지")

    ⚠️ 주의할 점¶

    • 파일 이름 확인: CSV 파일 이름과 코드의 파일 이름이 정확히 일치해야 해요
    • 한글 깨짐: 한글이 깨진다면 pd.read_csv('파일명.csv', encoding='utf-8') 또는 encoding='cp949'를 시도해보세요

    ✅ 점검하기¶

    1. df.head()는 무엇을 보여주나요?
    정답 확인데이터프레임의 처음 5개 행을 보여줍니다. 데이터가 제대로 불러와졌는지 확인할 때 유용해요!
    1. value_counts()는 무슨 일을 하나요?
    정답 확인각 값이 몇 번 나타나는지 세어줍니다. MBTI 유형별로 몇 명인지 알 수 있어요!
